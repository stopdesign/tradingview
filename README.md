# Автоматизация TradingView

## Установка зависимостей

```
pip install -r requirements.txt
```


## Скрипты

Лежат в папке `./src/`:

- `get_strategies.py` — выгружает список доступных стратегий.
- `get_sources.py` — для списка стратегий сохраняет исходники и настройки.
- `backtest.py` — запускает бэктест для комбинаций параметров.
- `get_data.py` — получает торговые данные.


## Конфигурация

Настройки лежат в папке `./src/settings/`:

- `settings.py` — настройки по умолчанию, пример для тестирования.
- `settings_local.py` — локальные настройки вне версионного контроля.

Нужно создать файл `settings_local.py` и сохранить там нужный конфиг.


## JWT-токен

Для работы скрипту нужен токен аутентификации пользователя TradingView.<br>
Предыдущие токены не переставали работать после даты экспирации.<br>
Токен можно взять из своего аккаунта TradingView вот такой командой:
```
console.log(ChartApiInstance.authTokenManager()._cache.token)
```

Внутри токена закодирован тарифный план и его ограничения:
```
{
  "user_id": 111111,
  "exp": 1663982547,
  "iat": 1663968147,
  "plan": "pro_realtime",
  "ext_hours": 1,
  "perm": "cbot,cme,cbot_mini,nymex,comex,cme_mini,amex",
  "study_perm": "tv-volumebyprice,tv-prostudies",
  "max_studies": 10,
  "max_fundamentals": 0,
  "max_charts": 4,
  "max_active_alerts": 100,
  "max_study_on_study": 9
}
```


В зависимости от подписки можно тестировать разное количество интервалов:
- 5K — бесплатно
- 10K — Pro и Pro+
- 20K — Premium

# Как этим пользоваться

0. Добыть JWT-токен и положить его в локальный конфиг.
1. Получить актуальный список публичных стратегий (get_strategies.py)
2. Получить исходники этих стратегий (get_sources.py).
3. Настройках списки стратегий, инструментов и таймфреймов для теста.
4. Запустить `backtest.py`.

# Выгрузка данных

Всего можно выгрузить около 20000 интервалов в данном таймфрейме.<br>
Это ограничение TradingView, которое не получается обойти.

```
python get_data.py SYMBOL TIMEFRAME [--session=regular]
```

## SYMBOL
Полный или краткий вариант биржевого тикера.<br>
YNDX загрузит данные для MOEX. NASDAQ:YNDX явно указывает на Nasdaq.

## TIMEFRAME
- 1D — 1 день
- 3H — 3 часа
- 15 — 15 минут

Если указан таймфрейм, для которого нет данных, то скрипт может вылетать.<br>
Кажется, **intraday** данные доступны только для платных юзеров.

## --session
Необязательный параметр. По умолчанию загружает данные для основной сессии.<br>
Допустимые значения могут быть разными для разных инструментов.<br>
Нужно смотреть варианты в поле Sessions информации об инструменте.
